# 🚀 ATS Checker AI Dashboard

An AI-powered ATS (Applicant Tracking System) Resume Analyzer built with Python and Streamlit that helps job seekers optimize their resumes for modern recruitment systems.

🌐 Live Demo: https://atschecker-j2uhjjyqemdp3h5guwraqi.streamlit.app/

---

## 📌 Project Overview

ATS Checker AI Dashboard is an intelligent resume analysis platform designed to evaluate resumes against job descriptions using NLP and AI-driven techniques.

The application provides:
- ATS compatibility score
- Keyword matching analysis
- Missing skills detection
- Resume optimization suggestions
- Interactive analytics dashboard

This project was developed as part of my internship tasks at DevelopersHub Corporation©.

---

## ✨ Features

### 🔍 ATS Resume Scoring
Analyze resumes and calculate ATS compatibility percentage.

### 🧠 AI-Powered Skill Matching
Detect relevant and missing keywords based on job descriptions.

### 📊 Interactive Dashboard
Modern analytics dashboard with visual insights and performance indicators.

### 📄 Resume Upload System
Supports resume uploads for real-time analysis.

### ⚡ Real-Time Recommendations
Provides actionable suggestions to improve resume ranking.

### 🎨 Modern UI/UX
Luxury futuristic interface designed using Streamlit customization and Plotly visualizations.
